About JOCKY

JOCKY is a forensic-first systems programming language and compiler ecosystem focused on low-level control, security, traceability and practical digital-forensics workflows.

The name

Just-in-time Optimized Compiler Kernel for sYstems

Written in capitals as JOCKY.

An ecosystem, not just a compiler

JOCKY includes the compiler, from lexer and parser through semantic analysis, type checking, LLVM IR generation and optimization passes. It also includes runtime components, standard libraries, JOCKYShield for code transformation, forensic tooling, and command-line and developer tools.

The project is open source and developed on GitHub. Anyone can read the code, report problems, propose features and send changes.

Focus areas

What guides the design

Language and compiler decisions are weighed against four goals.

  • Low-level control. Programmers decide how their code runs, close to the machine.
  • Security. The language and toolchain are designed with security in mind from the start.
  • Traceability. It should be possible to follow code from source to binary and understand every step.
  • Practical forensics. Features should serve real digital-forensics workflows, not just theory.

Brand guidelines

You may use the JOCKY name and logo to refer to the language, and in community projects, articles, talks and tools that work with JOCKY. Please don't modify the logo, and don't suggest that the JOCKY project endorses your work unless it does.

For anything else, ask in Discussions.
